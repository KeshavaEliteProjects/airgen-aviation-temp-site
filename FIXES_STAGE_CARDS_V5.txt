AIRGEN STAGE CARDS V5 — READABILITY / SCROLL ISOLATION

- Existing stage/module data preserved.
- Existing stage transformation logic preserved.
- Removed the desktop fixed module-card height that was clipping descriptions.
- Cards now use a compact but readable 2-column layout.
- Module descriptions get up to four readable lines on normal desktop heights.
- Very short desktop viewports use a slightly tighter variant without making text tiny.
- The detail panel can internally scroll only when its content genuinely exceeds
  the available height.
- Wheel/touch gestures over a scrollable detail panel are isolated from the
  page-level Journey transformation.
- Mobile/compact behavior remains one-column for modules.
